# MediChain Frontend

This project is the **frontend setup** for the MediChain application — a healthcare data management system built with **React**, **Vite**, and **Tailwind CSS**.

---

## Setup Overview

This setup covers the initial frontend configuration based on the Jira tasks:

1. **Frontend Setup**
2. **Initialize React project using Vite**
3. **Configure Tailwind CSS themes and fonts**
4. **Setup project structure**

---

## Tech Stack

- **React (Vite)**
- **Tailwind CSS**
- **PostCSS + Autoprefixer**
- **Node.js** (v18+ recommended)
